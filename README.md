# 공사정보 허브 v0.3.0.1

학교 행정실에서 같은 공사정보를 여러 양식에 반복 입력하는 일을 줄이기 위한 브라우저 기반 공사정보 허브입니다.

## v0.3.0.1 핵심 업데이트

- 공사 상세에 `공사정보 / 변경계약 / 서류` 탭 추가
- 제공받은 `공사서류 원클릭 프로그램(2026.4.)`의 행정기관 내부 양식을 기준으로 핵심 서류 3종 구현
  - 착공계(출력 제목: 착공신고서)
  - 준공계
  - 준공검사원
- 서류마다 별도 공사정보를 다시 입력하지 않고 현재 공사 마스터 데이터를 그대로 사용
- 서류에 필요한 값이 없을 때만 부족한 항목을 표시하고, 입력한 값은 공사정보/학교정보에 저장해 다음 서류에서 다시 사용
- A4 출력 미리보기 제공
- `인쇄 / PDF 저장`으로 브라우저 인쇄 기능 연결
- **v0.3.0.1 인쇄 핫픽스:** 미리보기 모달을 직접 인쇄하지 않고 A4 문서만 독립 인쇄 프레임으로 출력하여 1장 서류가 2장으로 밀리거나 상단이 비는 문제 수정
- 현재 계약금액을 사용하므로 변경계약 반영 후 준공서류에도 최종 계약금액이 자동 반영
- 양식 버전 `2026.04` 표시

## 기존 핵심 기능

- 여러 공사 독립 저장 및 자동저장
- `계약 → 착공 → 준공 → 지출 → 하자` 단계형 공사 상세
- 변경계약 이력 관리
- 업체 보관함 재사용
- 학교 공사 이력 현황.xlsx 불러오기/내보내기
- K-에듀파인 자료관리목록.xlsx로 기존 공사 보완
- 전체 JSON 백업/복원
- 입력한 공사정보와 업로드한 엑셀 내용 서버 미전송

## 배포

정적 웹앱입니다. Vercel에서 Framework Preset은 `Other`, Root Directory는 저장소 루트(`./`)로 배포할 수 있습니다.

중요: IndexedDB 데이터는 사이트 주소(origin)별로 저장됩니다. 같은 운영 URL을 유지하고 업데이트 전 중요한 데이터는 전체 백업을 권장합니다.

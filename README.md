# 공사정보 허브 v0.3.2

학교 행정실에서 같은 공사정보를 여러 양식에 반복 입력하는 일을 줄이기 위한 브라우저 기반 공사정보 허브입니다.

## v0.3.2 핵심 업데이트

- 서류 6종을 체크박스로 여러 개 선택
- `착공서류 / 준공서류 4종 / 지출서류 / 전체 6종` 빠른 선택
- 선택한 서류 전체의 부족정보를 중복 제거해 한 번에 입력
- 선택한 서류를 인쇄 순서대로 1/N 연속 미리보기
- 선택한 서류 전체를 A4 독립 페이지로 한 번에 인쇄/PDF 저장
- 최근 묶음 출력 3건을 공사별 로컬 이력으로 표시

- 제공받은 `공사서류 원클릭 프로그램(2026.4.)`의 행정기관 내부 양식을 기준으로 서류 3종 추가
  - 공사감독조서
  - 준공검사조서
  - 대금청구서
- 기존 3종을 포함해 총 6종 지원
  - 착공계(출력 제목: 착공신고서)
  - 준공계
  - 준공검사원
  - 공사감독조서
  - 준공검사조서
  - 대금청구서
- 공사감독·검사자·입회자는 학교 기본값을 우선 재사용하고, 없을 때만 입력 요청
- 준공정산금액·기지급액·공제금액은 공사정보에 한 번 저장해 준공/지출 서류에서 재사용
- 대금청구서 청구금액은 `현재 계약금액 - 기지급액 - 공제금액`으로 자동 계산
- 은행명·계좌번호·예금주명은 일반 공사/업체 정보와 분리된 `payouts` 저장소에 보관
- 업체 목록에서는 계좌번호를 표시하지 않고, 대금청구서 생성 시에만 사용
- 전체 백업/복원에 지급정보도 포함
- 기존 IndexedDB는 DB v2로 자동 업그레이드하며 기존 공사·업체 데이터는 유지

## 기존 핵심 기능

- 여러 공사 독립 저장 및 자동저장
- `계약 → 착공 → 준공 → 지출 → 하자` 단계형 공사 상세
- 변경계약 이력 관리
- 업체 보관함 재사용
- 학교 공사 이력 현황.xlsx 불러오기/내보내기
- K-에듀파인 자료관리목록.xlsx로 기존 공사 보완
- 전체 JSON 백업/복원
- 입력한 공사정보와 업로드한 엑셀 내용 서버 미전송
- A4 전용 인쇄 프레임으로 서류 1장 출력 안정화

## 배포

정적 웹앱입니다. Vercel에서 Framework Preset은 `Other`, Root Directory는 저장소 루트(`./`)로 배포할 수 있습니다.

중요: IndexedDB 데이터는 사이트 주소(origin)별로 저장됩니다. 같은 운영 URL을 유지하고 업데이트 전 중요한 데이터는 전체 백업을 권장합니다.

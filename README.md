# 공사정보 허브 v0.4.0

학교 행정실에서 같은 공사정보를 여러 양식에 반복 입력하는 일을 줄이기 위한 브라우저 기반 공사정보 허브입니다.

## v0.4.0 핵심 업데이트

### 계약서류 4종 추가

제공받은 `공사서류 원클릭 프로그램(2026.4.)`의 행정기관 내부 양식을 우선 기준으로 다음 계약서류를 추가했습니다.

- 공사도급표준계약서
- 승낙사항(공사집행)
- 사용인감계
- 수의계약 통합서약서 — 2페이지

기존 6종과 합쳐 총 10종을 지원합니다.

- 착공계(출력 제목: 착공신고서)
- 준공계
- 준공검사원
- 공사감독조서
- 준공검사조서
- 대금청구서

`계약서류 4종 / 착공서류 / 준공서류 4종 / 지출서류 / 전체 10종`을 빠르게 선택할 수 있고, 선택한 문서 전체의 부족정보를 중복 제거해 한 번만 입력한 뒤 묶음 인쇄할 수 있습니다.

### 서류 템플릿 구조 분리

v0.4.0부터 서류별 정의를 `documents.js`로 분리했습니다.

각 문서는 다음 정보를 독립적으로 가집니다.

- 문서 ID와 문서명
- 업무 단계
- 필수 데이터 필드
- 양식 버전
- 출력 페이지 수
- A4 출력 템플릿

앞으로 특정 서식이 변경되어도 공사 데이터 구조나 다른 문서 템플릿을 불필요하게 수정하지 않도록 하기 위한 구조입니다.

### 계약정보 재사용 강화

공사도급표준계약서와 승낙사항에 필요한 다음 값을 공사정보에서 재사용합니다.

- 계약번호
- 계약금액
- 계약보증금/보증률
- 계약일
- 착공예정일
- 준공기한
- 지연배상금률
- 물가변동 계약금액 조정방법
- 공종
- 하자보증률/금액/기간
- 업체명·대표자·사업자등록번호·주소·전화번호
- 기관명·주소·기관 대표자

계약보증금액·하자보증금액이 비어 있고 보증률과 계약금액이 있으면 출력 시 금액을 자동 계산할 수 있습니다.

## 기존 핵심 기능

- 여러 공사 독립 저장 및 자동저장
- `계약 → 착공 → 준공 → 지출 → 하자` 단계형 공사 상세
- 변경계약 이력 관리
- 업체 보관함 및 업체 지급정보 재사용
- 학교 공사 이력 현황.xlsx 불러오기/내보내기
- K-에듀파인 자료관리목록.xlsx로 기존 공사 보완
- 전체 JSON 백업/복원
- 선택 서류 연속 미리보기 및 A4 일괄 인쇄
- 입력한 공사정보와 업로드한 엑셀 내용 서버 미전송

## 데이터 호환

기존 v0.3.x와 동일한 IndexedDB 구조를 사용하며 기존 공사·업체·지급정보를 유지합니다. 같은 운영 URL에 덮어배포하면 브라우저에 저장된 기존 데이터가 이어집니다.

중요 데이터가 있다면 업데이트 전 `전체 백업`을 권장합니다.

## 배포

정적 웹앱입니다. Vercel에서 Framework Preset은 `Other`, Root Directory는 저장소 루트(`./`)로 배포할 수 있습니다.

IndexedDB 데이터는 사이트 주소(origin)별로 저장되므로 실제 업무자료는 하나의 Production URL에서 관리하는 것을 권장합니다.

# 공사정보 허브 v0.2.1

학교 행정실에서 같은 공사정보를 여러 양식에 반복 입력하는 일을 줄이기 위한 브라우저 기반 공사정보 허브입니다.

## v0.2.1 핵심 업데이트

- 공사 상세를 `계약 → 착공 → 준공 → 지출 → 하자` 단계형으로 재구성
- 현재 단계만 우선 펼쳐지고 완료/미래 단계는 접어서 화면 복잡도 감소
- 공사목록 상태를 `계약 준비 / 착공 대기 / 공사 진행중 / 준공검사 대기 / 지출 대기 / 완료`로 세분화
- 현재 단계에서 필요한 정보만 `지금 확인할 것`으로 표시
- 변경계약 이력 추가
  - 변경계약일
  - 변경 전·후 계약금액
  - 변경 전·후 준공기한
  - 변경 사유
- 변경계약 등록 시 현재 계약금액·준공기한 자동 반영
- 최초 계약금액은 별도로 보존
- 기존 v0.1~v0.2 IndexedDB 프로젝트 구조와 호환

## 기존 핵심 기능

- 여러 공사 독립 저장 및 자동저장
- 업체 보관함 재사용
- 학교 공사 이력 현황.xlsx 불러오기/내보내기
- K-에듀파인 자료관리목록.xlsx로 기존 공사 보완
- 전체 JSON 백업/복원
- 입력한 공사정보와 업로드한 엑셀 내용 서버 미전송

## 배포

정적 웹앱입니다. Vercel에서 Framework Preset은 `Other`, Root Directory는 저장소 루트(`./`)로 배포할 수 있습니다.

중요: IndexedDB 데이터는 사이트 주소(origin)별로 저장됩니다. 같은 운영 URL을 유지하고 업데이트 전 중요한 데이터는 전체 백업을 권장합니다.

## 다음 단계

v0.3에서는 현재 공사 마스터 데이터를 그대로 사용해 착공계·준공계·준공검사원·준공검사조서·대금청구서 등 실제 내부 공사서류 자동생성을 연결하는 방향을 예정합니다.

# 공사정보 허브 v0.2

학교 행정실에서 같은 공사정보를 여러 양식에 반복 입력하는 문제를 줄이기 위한 브라우저 기반 공사정보 관리 도구입니다.

## v0.2 반복입력 절감 UX

- 첫 화면을 `새 공사 직접등록 / 기존 공사이력 불러오기 / 에듀파인으로 정보 업데이트` 3가지 시작 흐름으로 재구성
- 새 공사 생성은 공사명만 필수이며, 착공일·준공기한 등 아직 생기지 않은 정보는 상세 화면에서 나중에 입력
- 업체 보관함을 선택하면 대표자·사업자번호·주소·전화·면허를 공사에 재사용
- 학교 공사이력과 K-에듀파인 자료관리목록을 서로 다른 작업으로 명확히 안내
- Excel 반영 전 `새 공사 / 자동 보완 / 확인 필요 / 변경 없음` 건수를 보여주는 동기화 결과 화면 강화
- 동일 자료를 다시 올렸을 때 실제 변경이 없는 공사는 업데이트 처리하지 않고 `변경 없음`으로 표시
- 값 충돌은 기존값을 기본 유지하며 사용자가 선택한 항목만 Excel 값으로 변경


## v0.1.3 공사이력 양식 교체

- 다운로드되는 공사이력 Excel 템플릿을 새 `학교 공사 이력 현황.xlsx` 양식으로 교체
- 새 양식의 1행 헤더 / 2행 데이터 구조에 맞춰 내보내기 로직 수정
- 기존 감사용 양식(4행 헤더 / 5행 데이터)도 불러올 수 있도록 import 로직 호환 유지
- 공사이력 다운로드 파일명을 `학교 공사 이력 현황.xlsx` 형태로 정리

## v0.1.2 UI 보완

- 날짜 입력을 브라우저 기본 date UI 대신 `YYYY - MM - DD` 4자리·2자리·2자리 고정 입력으로 변경
- 새 공사 및 공사 상세 입력을 PC에서도 한 줄씩 세로 흐름으로 변경
- 8자리 날짜 붙여넣기 및 월·일 1자리 입력 시 포커스 이탈 후 2자리 보정 지원

- 업체 보관함으로 업체정보 재사용

- 새 학교 공사 이력 현황 양식의 31개 열과 서식을 유지한 Excel 내보내기

- 충돌값은 자동 덮어쓰지 않고 현재값/엑셀값 선택
- 전체 공사·업체·학교정보 JSON 백업/복원
- 서버 DB, 분석도구, 광고, 외부 API 없음

## 데이터 처리 원칙

입력한 공사정보와 업로드한 Excel 내용은 서버로 전송하지 않습니다. Excel 분석과 공사정보 저장은 사용 중인 브라우저에서 처리합니다.

정적 페이지 자체를 내려받기 위한 일반적인 웹 접속은 발생합니다. 공사정보를 URL query string에 넣지 않으며, 외부 CDN을 런타임에 호출하지 않습니다.

### 저장 위치

공사/업체/학교정보는 브라우저의 IndexedDB에 저장됩니다. 브라우저 데이터 삭제, PC 교체, 사용자 프로필 삭제 시 사라질 수 있으므로 `전체 백업`을 정기적으로 사용하세요.

`전체 백업(JSON)`은 앱 복원·인수인계용이며 `공사이력 Excel`은 감사·업무용 결과물입니다.

## 엑셀 형식

### 감사용 공사이력현황

새로 제공된 `학교 공사 이력 현황.xlsx`의 열 구성과 서식을 기준으로 합니다.

`회계연도 / 번호 / 공사명 / 계약상대자 / 계약방법 / 계약금액 / 예정가격 / 낙찰율 / G2B/S2B / 계약일 / 착공일 / 현장대리인 자격증종류 / 준공기한 / 준공일 / 준공검사원발행일 / 준공검사원 문서등록일 / 준공검사조서작성일 / 선금지급여부 / 세금계산서 발행일 / 지출일 / 지출금액 / 하자보증서·각서 / 등록면허종류 / 하자기간 / 전화번호 / 대표 / 사업자번호 / 재원구분 / 공사대장출력 / 비고`

내보내기는 프로젝트에 포함된 `assets/audit-template.xlsx`를 기반으로 하므로 새 학교 양식의 열 너비, 헤더, 셀 서식이 유지됩니다.

### K-에듀파인 자료관리목록

`계약번호`, `계약명`, `계약일자`, `계약금액`, `계약상대자`, `착공일자`, `준공일자`, `실준공일자`, `예정가격`, `최초계약금액`, `계약보증`, `하자보증`, `검사검수`, `대금지급` 등 확인 가능한 항목을 공사 마스터에 보완합니다.

`목적물`이 공사가 아닌 행은 v0.1에서 제외합니다.

## 실행

정적 웹앱이므로 GitHub Pages 또는 Vercel에 그대로 배포할 수 있습니다.

로컬 확인 시에는 `file://`로 직접 열기보다 간단한 정적 서버를 사용하세요. 감사용 Excel 내보내기가 같은 출처의 템플릿 파일을 읽기 때문입니다.

```bash
python -m http.server 8080
```

이후 브라우저에서 해당 폴더의 `index.html`에 접속합니다.

## 보안 설정

- 런타임 외부 CDN 없음
- JSZip은 프로젝트 내부 `vendor/`에 포함
- Vercel 배포 시 `vercel.json`으로 CSP, nosniff, Referrer-Policy, Permissions-Policy 적용
- GitHub Pages에서는 `index.html`의 CSP meta가 기본 방어선 역할
- 주민등록번호 입력필드 없음
- 계좌번호/은행정보는 v0.1 공사 마스터에 넣지 않음

# 공사정보 허브 v0.4.3.8

학교 행정실의 반복적인 공사정보 입력을 줄이기 위한 브라우저 기반 공사관리·서류생성 도구입니다.

서식과 안전점검 항목은 서울시교육청 교육시설안전과 **「공사서류 원클릭(간소화)프로그램」(2026.5.수정)** 버전을 기준으로 구성했습니다.

## v0.4.3.8

- 현재 공사 화면 상단에서 `공사 삭제`를 바로 찾을 수 있도록 하고, 더보기 메뉴에 `공사자료 전체 초기화` 추가
- 전체 초기화는 공사·체크리스트·서류 입력값만 삭제하고 학교 기본정보·업체 보관함·지급정보는 유지
- 모든 안전·보건 체크리스트 카드의 행동을 `체크리스트 작성 / 빈 양식 미리보기` 2개로 통일
- 체크리스트 작성·수정 후 저장하면 작성본 미리보기로 이어지며, 빈 양식은 체크값·서명 없이 미리보기와 인쇄 가능
- 모든 개별 서류 미리보기 상단에 부족정보 또는 출력정보 상태를 항상 표시
- 미리보기의 `입력정보 수정`에서 주소·업체·계약정보 등 해당 서류에 쓰이는 값을 바로 수정하고 다시 미리보기 가능
- 부족정보가 있는 작성본은 미리보기는 허용하되 인쇄 전에 입력을 요구하여 빈칸 출력 실수를 방지

## v0.4.3.7

- 공사관리대장과 에듀파인 자료 불러오기에 드래그앤드롭 업로드 지원
- 에듀파인 자료관리 경로를 `학교회계 > 계약관리 > 계약자료관리 > 자료관리`로 안내
- 내부 공사관리대장 템플릿명을 `공사관리대장.xlsx`로 통일
- 수도·전기료 납부각서에서 현장대리인을 선택 입력하거나 공란으로 출력 가능
- 모든 체크리스트 작성본 인쇄에 점검자 펜 서명 / 서명 없이 출력 선택 적용
- 하자검사조서 카드 버튼을 미리보기·인쇄/PDF 중심으로 단순화
- 미리보기 중 경고가 dialog 뒤로 가려지지 않도록 모달 내부 경고영역 추가

## v0.4.3.6

- 하자검사조서 검사자·입회자 출력 방식을 `기본값 / 공란 출력 / 입력값 출력` 3가지로 분리하고 기본값 모드를 기본 선택으로 변경
- 하자검사조서 카드에 `미리보기`와 `인쇄 / PDF` 버튼을 항상 노출
- 수의계약 통합서약서의 [붙임1] 수의계약 배제사유에서 누락된 세부 조건·주석·제33조 관련 세부항목·특별재난지역 조건 보완
- 안전·보건 공통 체크리스트 외 업체 작성 체크리스트의 저장 후 출력 흐름 복구

## v0.4.3.5

- 앱의 기존 `공사이력/학교 공사 이력 현황` 표현을 `공사관리대장`으로 정리하고 엑셀 내보내기 파일명도 `공사관리대장.xlsx`로 통일
- 수의계약 통합서약서에 예·아니오·해당없음 선택 입력 기능 추가. 선택내용을 저장해 작성본으로 출력하거나 체크하지 않은 빈 양식으로 출력 가능
- 하자검사조서의 검사자·입회자 직위·성명을 검사 기록에서 입력하고 미리보기에서 출력 방식을 선택 가능

## v0.4.3.4

- 수도광열비 계산식 산식을 원본 엑셀 예시와 재검증: `(직재 + 직노) × ((공사종류 + 공사기간 + 공사규모) / 3)` 후 10원 미만 절사 방식 유지
- 하자검사조서의 검사자·입회자 `성명`은 저장값과 무관하게 모두 공란 출력하고 `(인)`만 표시
- 성명 공란에 밑줄을 제거하고 실제 기재 공간만 확보

## v0.4.3.3

- 수도광열비 계산식에 `직접재료비(직재) + 직접노무비(직노) = 계산기준금액`을 명확히 표시
- 공사종류·공사기간·공사규모의 실제 적용 요율을 강조하고, 요율 합계 → 평균요율 → 계산값 → 10원 미만 절사까지 검산 흐름을 출력
- 하자검사조서의 검사자 성명은 저장값과 무관하게 출력물에서 공란으로 유지
- 하자검사대장의 하자검사자 열도 이름을 자동 출력하지 않고 공란으로 유지
- 하자보수보증금 납부서의 부족정보 안내에서 `defectSecurityType`이 노출되던 오류를 `하자보증방법`으로 수정

## v0.4.3.2

- 수도·전기료 납부각서 대표자·현장대리인 이름칸과 `(인)` 칸을 분리해 도장 위치 고정 및 공란 필기공간 확보
- 서류 탭의 원클릭 기준 자료 안내를 독립된 강조 배너로 개선하고 아래 영역과 간격 확보
- 수도광열비 계산식 인쇄 시 A4 가로 크기(297×210mm)를 최종 인쇄 CSS로 재강제하고 가독성 조정
- 안전·보건 체크리스트 카드/작성화면에 출력 전 점검자 서명 기능과 비저장 안내 추가
- 서명 패드의 마우스 커서를 펜촉 모양으로 변경하고 미지원 환경은 기존 crosshair로 대체

## v0.4.3.1

- 서명 이미지는 현재 인쇄에만 사용하고 브라우저 저장소·JSON 백업에는 저장하지 않음
- 업체 작성 체크리스트의 빈 양식 묶음 인쇄 지원
- 하자검사조서 검사자·입회자를 검사 시점별 직위/성명으로 분리하고 기본 공란 처리
- 하자검사조서 공사기간 `~` 좌우 세로선 제거
- 수도·전기료 납부각서는 현장대리인 이름이 없어도 공란 양식 출력 가능
- 착공서류 2종 묶음 선택 추가: 착공계 + 수도·전기료 납부각서

- 화면 상단·서류 탭·도움말·푸터에 허브 버전과 원클릭 기준 자료 표기

## 데이터 처리

공사정보와 업로드한 Excel은 브라우저 내부에서 처리·저장합니다. 서버 DB를 사용하지 않습니다. 전체 백업(JSON)은 인수인계/복원용이며 지급정보를 포함할 수 있으므로 안전하게 보관하세요.

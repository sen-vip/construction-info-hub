# 공사서류 작성지원 v0.5.1.6

학교 행정실에서 공사 관련 서류를 빠르게 작성·확인·출력하기 위한 브라우저 기반 작성지원 도구입니다. 공통정보를 한 번 입력하면 여러 서류에 재사용합니다.

서식과 안전점검 항목은 서울시교육청 교육시설안전과 **「공사서류 원클릭(간소화)프로그램」(2026.5.수정)** 버전을 기준으로 구성했습니다.



## v0.5.1.6

- 출력 서식의 `계약연월일`, `착공연월일`, `준공연월일` 표기를 붙여쓰기로 통일
- 공사관리대장의 자동작성 안내 문구 삭제

## 데이터 처리

공사정보와 업로드한 Excel은 브라우저 내부에서 처리·저장합니다. 서버 DB를 사용하지 않습니다. 전체 백업(JSON)은 인수인계/복원용이며 지급정보를 포함할 수 있으므로 안전하게 보관하세요.

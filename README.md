# 공사정보 허브 v0.4.1

같은 공사정보를 여러 번 입력하지 않기 위한 학교 행정실용 로컬 웹앱입니다.

## v0.4.1 핵심 업데이트

이번 버전은 업체 제출서류보다 **행정기관이 직접 작성·관리하는 서류와 공사관리 흐름을 우선**합니다.

- 공사대장 추가
- 하자검사 기록 다건 누적
- 하자검사조서 추가
- 하자대장 추가
- 하자 시작일 + 담보기간으로 하자 종료일 자동 계산
- 완료공사 목록에 하자종료일 / D-day 표시
- 수도·전기료 계산 도구 추가
- 계산 결과를 대금청구서 공제금액에 바로 반영
- 서류 화면을 `행정기관 작성·관리 / 업체 제출·징구`로 재분류
- 기존 10종 + 신규 3종 = 총 13종 인쇄서류

## 수도·전기료 계산

기존 「공사서류 원클릭 프로그램(2026.4.)」의 `31.수도전기료계산식`을 기준으로 구현했습니다.

- 2024년도 완성공사 원가통계 경비율 기준
- 공사종류 / 공사기간 / 공사규모 요율 평균 적용
- 전기·통신·소방·전문공사는 원본 안내처럼 건축요율 적용
- 계약금액은 부가세 제외 금액으로 공사규모 구간 판단
- 직접재료비 + 직접노무비를 기준으로 전력비·수도광열비 계산
- 결과를 대금청구서 `공제금액`에 바로 연결

## 데이터 저장

- 서버 DB 없음
- 입력 공사정보와 업로드한 Excel 내용은 브라우저에서 처리
- 공사/업체/지급정보는 IndexedDB에 저장
- 전체 백업 JSON 및 감사용 공사이력 Excel 내보내기 지원

같은 Vercel 주소에 업데이트하면 기존 v0.4.0 데이터 구조와 호환됩니다.
